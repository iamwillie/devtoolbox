# DevToolbox

A fast, privacy-focused collection of everyday developer utilities built entirely with **HTML, CSS, and vanilla JavaScript**.

Everything runs primarily in your browser, with no backend required.

## Tools

* JSON Formatter & Validator
* JWT Decoder
* UUID Generator
* Unix Timestamp Converter
* Base64 Encoder / Decoder
* URL Parser & Encoder
* Regex Tester
* QR Code Generator
* Text Transformer
* Hash Generator

## Features

* Local-first processing
* Light and dark themes
* Responsive desktop/mobile interface
* `Ctrl/Cmd + K` command palette
* Favourite and recently used tools
* Smart paste detection
* Local file hashing with Web Crypto
* Copy-to-clipboard actions
* No sensitive input stored by default
* Single-file application

## Usage

Download or clone the repository and open:

`DevToolbox.html`

in any modern browser.

No build process, dependencies, or server required.

## Privacy

Developer data such as JSON, JWTs, URLs, files, hashes, and pasted text is processed locally wherever possible.

`localStorage` is only used for non-sensitive preferences such as theme, favourites, and recently used tools.
